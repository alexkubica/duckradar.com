# DuckRadar Repo Map

DuckRadar is in sales validation for a `$49/site/mo` monthly SEO decision brief for solo consultants and micro-agencies.

## Start Here

1. Read `AGENTS.md` for repo operating rules.
2. Read `CURRENT_STATE.md` for the live handoff.
3. Read `TASKS.md` for the current task board.
4. Read the strategy source-of-truth files in `docs/strategy/` before making offer, ICP, pricing, or validation recommendations.

## Directory Map

- `docs/strategy/`: offer, requirements, validation plan, decision log, workflow, and agent task source-of-truth docs.
- `docs/research/`: source-heavy market and customer research.
- `docs/payments/`: Paddle/payment setup notes.
- `docs/fulfillment/`: onboarding, GSC export, and report delivery templates.
- `reports/`: public/sample reports.
- `sample-data/`: synthetic data for manual workflow testing.
- `site/`: static DuckRadar website deployed through Vercel.
- `.codex/agents/`: custom startup-team agent definitions.
- `.agents/skills/`: reusable project skills.
- `.agents/templates/`: reusable artifact templates.

## Current Working Rule

Keep the remote repo synced with small, coherent commits after meaningful changes. Strategy and handoff changes should be pushed as readily as code changes so future Codex sessions start from the same state.
