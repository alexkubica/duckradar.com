# DuckRadar Client Update Example: Authentix Israel

Site: https://www.authentix.co.il  
Example date: 2026-06-14  
Data status: public crawl and search sample only. Real GSC data would replace the placeholder opportunity rows.

## Client Update

Authentix has a clean public SEO base: working HTTPS, a live sitemap, current package and portfolio pages, Hebrew RTL markup, article pages, and correct redirects for two older URLs. The next useful SEO move is not another broad audit. It is choosing one commercial service page to strengthen based on real Search Console demand.

The likely first candidate is either social media management for businesses or Reels and TikTok production for businesses. Both match existing package content, article content, and the services Authentix appears to sell.

## What Changed

- The current sitemap exposes 11 URLs, including homepage, packages, portfolio, articles, and legal pages.
- Old URLs for influencer and workshop pages redirect to current pages.
- One old branding URL returns 404.
- The packages page is the strongest commercial page currently visible.
- The article base supports the commercial offer, but it needs stronger links into the package or service pages.

## Why It Matters

Authentix already has useful pages, but the commercial intent is split between packages, articles, and portfolio examples. Search Console should tell us which topic already has impressions. That page should get the first content and internal-linking pass.

Without GSC, we can see structure and obvious gaps. We cannot honestly rank the real opportunities by impressions, clicks, CTR, or average position.

## Top Decision This Month

Pick one service theme from GSC and turn it into a clearer money page.

Recommended first pass:

`ניהול סושיאל מדיה לעסקים`

Backup if GSC shows stronger demand:

`הפקת רילסים וטיקטוק לעסקים`

## Next 3 Actions

1. Export the last 3 months of GSC queries and pages, then choose the service theme with the best mix of impressions and average position.
2. Redirect or rebuild the old `/מיתוג` URL if GSC shows impressions, clicks, or backlinks for it.
3. Add a focused service page or expand the packages page section around the winning topic, then link to it from the homepage, article, packages page, and relevant portfolio examples.

## AI And Local Visibility Note

No AI visibility provider was used for this public example.

For a real monthly brief, DuckRadar would first check whether the site has access to Google's Search Console generative AI performance reports. If available, those first-party observations would be summarized. If unavailable or too sparse, the report would say so clearly.

Directional prompt checks can still be useful, but only as sampled evidence. For Authentix, useful prompts would be around:

- Recommended digital marketing agency for small businesses in Israel
- Social media management for businesses in Israel
- Reels and TikTok production for businesses in Israel
- Business landing page and WhatsApp lead flow in Israel

These checks should be used to spot source gaps and message gaps, not to promise AI answer inclusion.
