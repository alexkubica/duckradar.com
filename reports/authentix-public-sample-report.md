# Public Sample Report: Authentix Israel

Site: https://www.authentix.co.il/  
Date: 2026-05-17  
Scope: Public-only sample. No Google Search Console or GA4 access was available.

## Summary

Authentix has a crawlable Wix site with a clear brand, social/content services, sitemap, canonical URLs, contact details, and basic LocalBusiness/WebSite schema. The main opportunity is not technical cleanup; it is turning the site from a brand brochure into search-intent landing pages that can capture Hebrew service demand around social media management, TikTok/Reels production, business video, personal branding, influencer marketing, and workshops.

## What We Could Verify Publicly

- `https://authentix.co.il/` redirects to `https://www.authentix.co.il/`.
- `robots.txt` allows crawling and references `https://www.authentix.co.il/sitemap.xml`.
- Sitemap index points to `pages-sitemap.xml`.
- Page sitemap lists 6 URLs: homepage, `עבודות`, `סדנאות`, `מיתוג`, `משפיענים`, `חבילות`.
- Homepage title: `אותנטיקס ישראל | הבית שלך בדיגיטל`.
- Homepage meta description describes Authentix as a marketing agency specializing in photography, content creation, social media management, and brand image.
- LocalBusiness and WebSite JSON-LD schema exist on the homepage.
- Wix serves the page with `content-language: en`, while the visible site is Hebrew.

## Public Findings

### 1. Service Pages Are Too Thin For Search Intent

The site has relevant service URLs, but the public content appears closer to package/brand copy than full search landing pages. For SEO, each core service needs enough context to satisfy a buyer comparing providers.

Recommended first pages to strengthen:

- `ניהול סושיאל מדיה`
- `סוכנות סושיאל מדיה`
- `צילום תדמית לעסק`
- `סרטון תדמית לעסק`
- `סדנת טיקטוק לעסקים`
- `יצירת תוכן לעסקים`
- `ניהול טיקטוק לעסק`

### 2. Some Pages Lack Unique Meta Descriptions

Public extraction found repeated generic descriptions on homepage, work, workshops, and packages. `מיתוג` and `משפיענים` did not expose a meta description in the same static check.

Recommended action:

- Write unique Hebrew title/meta descriptions for each service page.
- Make each description match search intent, not just brand positioning.

### 3. Packages Page Has Commercial Intent But Needs Better Structure

The packages page is valuable because it lists actual offers. It should become a stronger commercial landing page.

Recommended action:

- Add short intro copy above packages explaining who each package is for.
- Add internal links from each package to a deeper service page.
- Add FAQ content for pricing, deliverables, timeline, usage rights, and who writes scripts.
- Add CTA near each package, not only at the bottom.

### 4. Portfolio/Logos Need Case-Study Context

The homepage shows brand logos and work credibility, but search engines and buyers need context.

Recommended action:

- Turn portfolio examples into short case studies.
- Include client type, challenge, service delivered, platform, and outcome.
- Link case studies back to relevant service pages.

### 5. LocalBusiness Schema Exists But Can Be Enriched

Homepage has LocalBusiness and WebSite schema. The LocalBusiness schema includes name, URL, image, country, and phone.

Recommended action:

- Add `sameAs` links for Instagram, TikTok, Facebook.
- Add `areaServed`, `description`, and service categories where appropriate.
- Add stronger organization/contact details if accurate.

### 6. Language Signal Should Be Reviewed

The HTTP response reports `content-language: en`, but the visible page is Hebrew.

Recommended action:

- Check Wix language/locale settings.
- If the site targets Hebrew/Israel, make sure HTML language and site language settings reflect Hebrew/Israel.
