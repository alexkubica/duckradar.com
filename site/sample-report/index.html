Public-only sample

Example monthly client update.

This sample shows the short format DuckRadar is built around: what changed, why it matters, and what to do next. Paid reports use customer-provided Google Search Console data, so they can include actual queries, pages, impressions, clicks, CTR, and position opportunities.

This sample does not use private Google Search Console data and should not be treated as a complete paid report.

Client update summary

Authentix has a clean public SEO base: working HTTPS, a live sitemap, current package and portfolio pages, Hebrew RTL markup, article pages, and correct redirects for two older URLs. The next useful SEO move is not another broad audit. It is choosing one commercial service page to strengthen based on real Search Console demand.

The likely first candidate is either social media management for businesses or Reels and TikTok production for businesses. Both match existing package content, article content, and the services Authentix appears to sell.

What changed

  • The current sitemap exposes 11 URLs, including homepage, packages, portfolio, articles, and legal pages.
  • Old influencer and workshop URLs redirect to current pages.
  • One old branding URL returns 404 and should be checked against GSC before deciding whether to redirect or rebuild it.
  • The packages page is the strongest commercial page currently visible.
  • The article base supports the commercial offer, but needs stronger links into package or service pages.

Why it matters

Authentix already has useful pages, but commercial intent is split between packages, articles, and portfolio examples. Search Console should tell us which topic already has impressions. That page should get the first content and internal-linking pass.

Top decision this month

Pick one service theme from GSC and turn it into a clearer money page.

Recommended first pass: ניהול סושיאל מדיה לעסקים. Backup if GSC shows stronger demand: הפקת רילסים וטיקטוק לעסקים.

Next 3 actions

  • Export the last 3 months of GSC queries and pages, then choose the service theme with the best mix of impressions and average position.
  • Redirect or rebuild the old branding URL if GSC shows impressions, clicks, or backlinks for it.
  • Add a focused service page or expand the packages page section around the winning topic, then link to it from the homepage, article, packages page, and relevant portfolio examples.

Search Console opportunities

The real customer version would use GSC rows here. The decision logic looks for:

  • Queries in positions 5 to 20 with impressions.
  • Pages with high impressions and low CTR.
  • Articles getting commercial queries.
  • Old URLs still receiving impressions or clicks.
  • Portfolio pages receiving branded search that could support conversion.

AI and search visibility note

For a real monthly brief, DuckRadar first checks whether the site has access to Google's Search Console generative AI performance reports. If available, those first-party observations are summarized. If unavailable or too sparse, the report says so clearly.

Directional prompt checks can still be useful, but only as sampled evidence for source gaps and message gaps. They are not ranking reports and do not guarantee AI answer inclusion.

Content brief

Page to create or update: ניהול סושיאל מדיה לעסקים.

The page should explain what monthly social media management includes, who it is for, which platforms are covered, the process, portfolio examples, package links, common questions, and the WhatsApp call to action.
