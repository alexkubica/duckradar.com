# Evidence Review

Use this to keep strategy grounded in evidence rather than vibes.

## Steps

1. Gather source links.
2. Label each source as primary, review-site, community, competitor, interview, or inference.
3. Separate direct evidence from interpretation.
4. Extract repeated customer language.
5. Identify contradictions or weak evidence.
6. State confidence level.

## Output

- Evidence summary.
- Repeated patterns.
- Customer language.
- Contradictions.
- Confidence score.
- Decision implication.
