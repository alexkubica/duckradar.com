# Landing Page Test

Use this to test demand before building product.

## Steps

1. Pick one ICP and one pain.
2. Write one promise.
3. Show concrete deliverables.
4. Include price or starting price unless there is a deliberate reason not to.
5. Add one CTA.
6. Define traffic source and tracking.
7. Define success and kill criteria.

## Output

- Page angle.
- Hero copy.
- Offer section.
- CTA.
- Traffic plan.
- Metrics.
- Kill criteria.
