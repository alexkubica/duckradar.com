# ICP Narrowing

Use this before product, sales, marketing, or build work when the buyer is unclear.

## Steps

1. List possible buyers.
2. Score each buyer on urgency, reachability, willingness to pay, repeat usage, and ability to provide data access.
3. Pick one beachhead ICP.
4. Define buyer, user, painful job, budget source, and trigger event.
5. Explicitly list exclusions.
6. Define the next validation action.

## Output

- Recommended ICP.
- Why this ICP now.
- Exclusions.
- Top 3 buying triggers.
- Next validation action.
