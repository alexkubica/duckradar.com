# Validation Experiment

Use this when planning any experiment: outreach, landing page, paid sprint, pricing, onboarding, retention, or channel test.

## Steps

1. State the hypothesis.
2. Define the target segment.
3. Define the action that proves demand.
4. Define the measurement window.
5. Define success criteria.
6. Define kill or pivot criteria.
7. Define what will be done next for each outcome.

## Output

- Hypothesis.
- Segment.
- Test design.
- Metrics.
- Success criteria.
- Kill criteria.
- Next decision.
